# Bettermode Weekly Growth Tracker
**Owner:** Kat Kennedy
**Cadence:** Weekly — pull every Monday morning
**Purpose:** Track community-level growth week over week — new members, traffic, and engagement. Separate from post-level view tracking (`tracking-bettermode-weekly.md`).

---

## How to Pull

1. Go to **Bettermode Admin → Reports → Analytics**
2. Set the date range to the **past 7 days** (Mon–Sun)
3. Record the values below — takes ~10 minutes

| Field | Where to find it |
|---|---|
| New members | Members section → "Net new members (last 7 days)" |
| Active members | Members section → "Active members (last 7 days)" |
| Total registered members | Members section → cumulative total |
| Page views | Page Views section → last 7 days |
| Unique visits | Page Views section → unique visits last 7 days |
| New posts | Posts section → new posts last 7 days |
| New replies | Posts section → new replies last 7 days |
| New reactions | Posts section → new reactions last 7 days |

**Backfill note:** Bettermode Analytics supports custom date ranges — you can pull historical weeks retroactively by setting the date range to a prior Mon–Sun window.
