## Mission

**`mission.md`** — The north star for everything in this repo. A place for Pros to connect with each other and with the org — building stronger partnerships and rapport with the people doing the work. Pro success, including reaching Blue, follows from building something worth showing up to.

## Strategy

**`bettermode-strategy-2026.md`** — The main strategy document. Five focus areas, each tied to a specific problem, data point, and measurable outcome.

| Focus Area | Core Problem |
|------------|-------------|
| New Pro Success (0–60 days) | Half of new Pros don't reach job 10 |
| High-Frequency Problem Scenarios | 40% of schedules hit a problem; Pros have no proactive guidance |
| Tier System Clarity | Rating/tier confusion is the #3 support ticket type |
| Expert Access Rotation (AMA Series) | HQ drives 32% of community activity; top topics need trusted expert voices |
| Pool Pro Space | Pool Pros have no dedicated community home; questions and sentiment live only on Facebook. Jeff Herman's team is producing Pool Pro content to feature in the space. |
